Install Instruction
1. Herunterladen anzeige.
(Der Download der Option hängt vom Autor ab)
2. Tippen Sie auf die Schaltfläche Installieren, Die App Mi Fit wird geöffnet. Stellen Sie sicher, dass diese App und Ihre Band bereits verbunden sind.
3. Tippen Sie in der unteren Navigation auf Profile.
4. Tippen Sie auf die Zeile Mi Smart Band 4.
5. Tippen sie auf die zeile Band display settings.
6a. Tippen Sie auf den dritte tab. Wenn es nur zwei Tabs gibt, fahren Sie mit Schritt 6b fort.
6b. Tippen sie auf den tab erste.
7. Wählen Sie angegebene anzeige und Synchronisieren aus.
