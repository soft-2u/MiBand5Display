FAQ Install Instructions Display
FAQ

Display:

After tap the Download button, please select Allow storage access. Then try again.

After tap the Download button, be sure to tap the Install button. Then the method selection dialog appears, select Add to Mi Fit app. If it still doesn't appear, try closing and reopening the Mi Fit app.

Note: if the method selection dialog doesn't appear, go to Settings and Reset installation method.

Note: also, you can install the Display faster by Sync via Bluetooth.

With Android 11 onwards: Sync via Bluetooth is the only way to install it.


General:

Just open the Mi Fit app once and connect to your mi smart band 5. Then switch to this application, select the Display/Icon/Font to be installed. The method selection dialog appears, select Sync via Bluetooth. Sync will take place.

Note: if the method selection dialog doesn't appear, go to Settings and Reset installation method.

Make sure Bluetooth and Location services are turned on, leaving mi smart band 5 near your device.

Note: Android 6 onwards announced Location permission is required for Bluetooth scanning to work.

Keep mi smart band 5 near your phone. Keep your phone on, avoid turning off the screen or locking it. Required: Bluetooth and Location services are turned on.

Note: Android 6 onwards announced Location permission is required for Bluetooth scanning to work.
